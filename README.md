# 粘贴公式修复（Paste LaTeX Fixer）

思源笔记插件：**粘贴时自动修复 LaTeX 并转换 MathML**，无需任何手动操作。

> 从 AI 聊天、网页、文档复制内容粘贴到思源时，公式经常显示为乱码/原文。本插件在粘贴时自动修复：
> `[ 公式 ]` 定界、`==========` 碎片、`*{b_i}` 下标丢失、矩阵 `\` 丢反斜杠、`(W_{ij})` 括号公式、
> 思源内部复制产生的 Markdown 转义（`y\=Wx`、`\\frac`）、裸 LaTeX 环境，并把网页 MathML / MathJax / KaTeX 公式转换为可渲染的公式块。
> 块级公式以思源内部格式插入（真公式块，不是行内降级）。

## 解决的问题

从 AI 聊天、网页、文档复制内容粘贴到思源时，公式经常显示为乱码/原文。本插件在粘贴时自动处理：

| 来源 | 处理方式 |
|---|---|
| AI 聊天文本（`[ 公式 ]` 定界、`==========` 碎片、`*{b_i}` 下标被斜体吃掉、矩阵 `\` 丢反斜杠） | 自动修复为思源可渲染的 `$$...$$` / `$...$` |
| 括号包裹的行内公式 `(W_{ij})`、`(a_t,b_t)` 等 | 转成 `$(W_{ij})$` / `$(a_t,b_t)$`（仅在含 LaTeX 命令或下标/上标时转换） |
| `\[ ... \]`、`\( ... \)`（Typora 等习惯） | 转换为 `$$...$$` / `$...$` |
| 裸 `math`、`equation`、`align`、`gather`、`cases`、矩阵等完整环境 | 自动补成行内或块级公式；未闭合环境原样保留 |
| 网页原生 MathML（Wikipedia、知乎等） | 转换为 LaTeX 公式 |
| MathJax 渲染的网页（mjx-container） | 提取 assistive MathML 转换 |
| KaTeX 渲染的网页 | 直接提取源码注解（`<annotation encoding="application/x-tex">`） |

修复后的内容走思源的 Markdown 粘贴路径，`$$...$$` 会直接变成公式块。

## 效果对比

粘贴前（AI 聊天复制来的原文）和粘贴后（思源笔记中的渲染结果）：

| 场景 | 修复前（AI 复制粘贴） | 修复后（粘贴到思源） |
|---|---|---|
| 定界公式 | `[ 公式 ]` 包裹、等号被 AI 画成 `==========` 分割线 | `$$L = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$` → 公式块 |
| 下标被斜体吃掉 | `*{b_i}*`（星号变斜体，下标丢失） | `$b_i \sim \mathcal{N}(0, \sigma^2)$` |
| 矩阵断行 | `[ a11 a12 ]`，`\` 换行符丢失 | `$$\begin{bmatrix} w_{11} & w_{12} \\ w_{21} & w_{22} \end{bmatrix}$$` |
| 括号公式 | `(W_{ij})` 原样粘贴，不渲染 | `$(W_{ij})$` → 行内公式 |
| 思源内部复制 | `y\=Wx`（Markdown 转义残留） | `$y = Wx$` |
| MathML 网页 | `<math>…</math>` 原文 | MathML → LaTeX → 公式块 |

> 表中"修复后"即粘贴进思源后的实际内容——思源自动渲染为数学公式，**全程零手动操作**。

## 安装

方式一（源码安装）：

```bash
git clone https://github.com/sihan-bzwj/siyuan-paste-fixer
cd siyuan-paste-fixer
npm install && npm run build
```

把 `dist/` 里的**内容**（`index.js`、`plugin.json`、`i18n/`、`README.md`）复制到思源数据目录的 `data/plugins/paste-fixer/` 下（没有就新建），重启思源后在 设置 → 插件 启用。

> 数据目录查找：思源 → 设置 → 关于 → 打开数据文件夹。
> 修改代码后重新构建，把 `dist/` 内容覆盖回去，完全退出并重启思源。

除了自动粘贴修复，还提供手动转换入口：**选中文本 → 右键"修复选中文本中的公式"**、顶栏 Σ 按钮、`Ctrl+P` 命令面板。

## 工作原理

双通道粘贴拦截，普通文本（代码、价格 `$5 and $10`、链接、函数调用）一律不动：

1. **事件总线通道**：思源主程序粘贴时给插件发 `paste` 事件，插件修复后通过 `resolve()` 返回载荷；
2. **DOM 通道**（兜底）：document 捕获阶段监听原生 `paste`，修复后以 `DataTransfer` 重新派发。

修复后的 Markdown 会转换成思源内部格式（`text/siyuan`）随粘贴附带——**块级公式以真公式块插入**（思源前端 Lute 只解析行内数学，直接给纯文本会把 `$$` 降级成行内公式）。MathML（含 MathJax/KaTeX 源码注解）转 LaTeX 后同样处理。

当剪贴板同时有 HTML 与纯文本时，插件按保真度选择来源：HTML 携带 `data-latex`、TeX annotation、MathJax v2 源码或 `alttext` 时优先 HTML；只有 MathML 反推结果而纯文本已含完整 LaTeX 时优先纯文本，避免同一公式重复或反推损失。

### LaTeX 修复规则

- `[ ... ]`（含 `\`、等号、下标/上标）→ `$$ ... $$`；`\[...\]`/`\(...\)` 同理
- 完整裸环境按类型包装：`math` → 行内，`displaymath`/`equation`/`align`/`gather`/`cases`/矩阵等 → 块级
- `( ... )` 含 LaTeX 命令或下标/上标 → `$ ... $`（函数调用 `f(x)`、`\left(`、英文短语、链接 URL 等一律不动）
- 思源内部复制的 Markdown 转义按上下文还原：`\\frac` → `\frac`、`b\_t` → `b_t`；合法字面转义（如 `x\_1`、`\text{A\&B}`）保留
- `*{...}` / `\*{...}` / `_*{...}` → `_{...}`（被 Markdown 斜体吃掉的下标）
- 行尾单个 `\` → `\\`（矩阵换行）；行内 `\` + 数字（`2\3\4`）→ `\\`
- `==========` 碎片行、公式片段间空行 → `=`（AI 渲染把等号画成了分割线）
- `$ x $`（两侧空格）→ `$x$`（否则思源不解析）
- 数学区中的 NBSP 转普通空格，零宽字符移除；正文与 Unicode 数学符号逐字保留
- 任意长度反引号/波浪线围栏、行内代码、链接 URL、图片路径、自动链接内部一律不处理；链接可见文字中的显式公式仍可修复
- 不完整环境、未闭合定界符和混合定界符不猜测补齐，优先保持原文结构

## 已知限制

- 网页含 MathML 时，为保证公式正确，其余富文本排版（加粗/图片等）会以纯文本形式粘贴（公式优先）；
- 从 Word 复制的 OMML 公式由思源内核处理，本插件不干预；
- 括号转换是保守的：`(a,b)`、`(T)`、`(i,j)` 这类无命令无下标的括号保持原文（无法与普通括号区分）；
- 行内 `$` 解析依赖思源设置"行内公式"开启（默认开启）。

src/mathml.ts      MathML/MathJax/KaTeX → LaTeX
test/              无头测试（KaTeX 校验）
